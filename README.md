# 三段法令ビューア

Lawtextの法令HTML表示を利用し、法律・施行令・施行規則を3列で閲覧する独立したサイトです。

## 使い方

- 各列上端の色付きバーの矢印をクリックすると、その列だけが2倍の幅になります。同じバーを再クリックすると等幅に戻り、別のバーをクリックすると拡大対象が切り替わります。幅変更時は各列の閲覧位置を維持します。
- 本文と付箋は画面で読みやすいゴシック体で表示します。

- 法令選択画面の「一覧から選ぶ」で五十音順の法律一覧を閲覧できます。分野や名前・読み・番号で絞り込み、40件ずつページを切り替えます。一括選択でも各列の個別選択でも利用できます。一覧はe-Gov APIから取得し、廃止と明記された法令を除外します。

- 最上部の「法令を選ぶ」→「3法令まとめて」で法律を検索すると、同名の施行令・施行規則を自動選択します。候補を確認・変更して、一括で3列を切り替えられます。該当する法令がない列は空欄にできます。
- 最上部の「法令を選ぶ」→「法律」「施行令」「施行規則」で法令名を検索します。法律・政令・省令をそれぞれ検索します。
- 各列の「条文へ移動」欄は、本文の上端に表示されている条番号と見出しにリアルタイムで追従します。附則の条文は「附則」と明記します。
- 「条文へ移動」で対象の条文を選びます。各列を個別にスクロールできます。
- 「政令で定める」「省令で定める」「委員会規則で定める」などの単語から、現在表示している下位法令の参照元へ移動できます。該当条項への参照が見つかった場合にリンクを表示し、複数候補は付箋で選択します。
- 各条文の下の「この条文を参照」から、参照元の施行令・施行規則などへ移動できます。
- 3列に含まれない法令は黄色い付箋に表示します。×またはEscapeで閉じられます。
- スマートフォンでは列をタブで切り替えます。

## データと制約

e-Gov法令API v2から表示時に取得します。各列に施行日を表示します。APIが使えない場合、初期表示の個人情報保護法・施行令・施行規則についてのみ2026年10月12日に取得した保存データを表示します。保存データは最新とは限りません。

Lawtextの解析機能を使って参照先を判定します。参照元のリンクは現在読み込んでいる3法令から生成します。解析できない参照はリンク化しません。同じ法令の複数箇所への参照は付箋にまとめて表示します。別法令の附則や別表など、本文の条・項・号以外の参照は現時点ではリンク化しません。

この版では法令本文の表示と列幅の比率変更を提供します。Lawtext本体の定義語ポップアップ、Word出力、XML・Lawtextファイル読み込みは移植対象に含めていません。別添画像はe-Gov側で確認してください。取得する版はe-Gov APIの既定選択に従います。

## 開発・移設

Node.js 20.19以上で `npm ci`、`npm run dev` を実行します。`npm run build` で生成されるdistを静的ホスティングのルートに配置してください。APIへの接続にはインターネット接続とブラウザからのアクセス許可が必要です。

ローカル作業用の `.openai/` 設定、依存関係の `node_modules/`、生成済みの `dist/` はリポジトリに含めません。

## 検証

`npm test` で参照解析・一覧・列幅切り替えのテストを実行できます。
